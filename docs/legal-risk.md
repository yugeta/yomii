# 著作権リスクと対策

```
Created : 2026.04.30
```

## 前提

Yomii は「自分が所有する書籍をスキャンして、スマホ等で読む」ための個人利用ツールとして設計されている。日本の著作権法では、私的使用のための複製（第30条）は認められているが、システムの設計次第では法的リスクが生じる。

---

## 1. 法的背景

### 1.1 私的使用のための複製（著作権法第30条）

> 個人的に又は家庭内その他これに準ずる限られた範囲内において使用することを目的とするときは、その使用する者が複製することができる。

**ポイント:**
- 「使用する者が」自ら複製する必要がある
- 家庭内またはそれに準ずる限られた範囲
- 営利目的の第三者による複製は対象外

### 1.2 自炊代行の判例

2013年の「自炊代行」訴訟で、業者が利用者に代わってスキャンする行為は私的複製に該当しないと判断された。

**Yomii への示唆:**
- サーバー側でファイル変換を行う場合、「誰が複製しているか」が問題になりうる
- ユーザー自身の操作で変換が行われる設計が重要

### 1.3 公衆送信権（第23条）

著作物をサーバーに置いて不特定多数がアクセスできる状態にすると、公衆送信権の侵害になる。

### 1.4 送信可能化権

サーバーにアップロードした時点で、実際にダウンロードされなくても「送信可能化」に該当する可能性がある。

## 2. リスク分類

### 🔴 高リスク

| リスク | 状況 | 法的問題 |
|--------|------|---------|
| 書籍データの共有 | ユーザーAがアップした書籍をユーザーBが読める | 公衆送信権侵害 |
| サーバーへの永続保存 | 変換済みデータがサーバーに残り続ける | 送信可能化 |
| 不特定多数へのアクセス | 認証なしで書籍データにアクセス可能 | 公衆送信権侵害 |
| 代行変換サービス化 | 「アップロードすれば変換します」という形態 | 私的複製の範囲外 |

### 🟡 中リスク

| リスク | 状況 | 法的問題 |
|--------|------|---------|
| 変換中の一時保存 | サーバーに一時的にデータが存在する | グレーゾーン |
| 家族間共有 | 家庭内で同一アカウントを使用 | 「家庭内」の範囲解釈 |
| クラウド保存 | Google Drive等に保存 | 個人利用なら問題なし |

### 🟢 低リスク

| リスク | 状況 | 法的問題 |
|--------|------|---------|
| クライアント完結 | ブラウザ内で変換・閲覧 | 私的複製の範囲内 |
| ローカル保存 | IndexedDB / OPFS に保存 | 私的複製の範囲内 |
| 個人のクラウド | 自分のGoogle Driveに保存 | 私的複製の範囲内 |

## 3. システムで実装すべき対策

### 3.1 サーバーにデータを残さない設計

**最重要。** 変換処理後、サーバー上のデータを確実に削除する。

```
[アップロード] → [変換] → [ユーザーにダウンロード] → [サーバーから即削除]
```

**実装:**
- 変換完了後、ダウンロード確認をもって一時ファイルを削除する
- 一定時間（例: 1時間）経過したら未ダウンロードでも強制削除する
- cronジョブで `data/tmp/` を定期的にクリーンアップする
- サーバーに書籍データのキャッシュを持たない

```php
// 例: 変換完了後の自動削除
function cleanup_after_download($uuid) {
    $dir = Common::get_uuid_dir($uuid);
    $json = Common::get_book_json($uuid);
    if (is_dir($dir))  { exec("rm -rf " . escapeshellarg($dir)); }
    if (is_file($json)) { unlink($json); }
}

// 例: cronで古いファイルを削除（1時間以上前のもの）
// 0 * * * * find /var/www/html/data/tmp -mmin +60 -delete
```

### 3.2 アクセス制御の実装

書籍データへのアクセスを本人に限定する。

**実装:**
- 変換済みデータのURLを推測不可能にする（UUID + ワンタイムトークン）
- ダウンロードリンクに有効期限を設ける
- 認証済みユーザーのみがアクセスできるようにする
- 他ユーザーのデータにアクセスできないことを保証する

```php
// ワンタイムトークン付きダウンロード
function generate_download_token($uuid) {
    $token = bin2hex(random_bytes(32));
    $expiry = time() + 3600; // 1時間有効
    // トークンを保存（ファイルまたはDB）
    save_token($uuid, $token, $expiry);
    return $token;
}

function validate_download($uuid, $token) {
    $saved = load_token($uuid);
    if (!$saved || $saved['token'] !== $token || time() > $saved['expiry']) {
        http_response_code(403);
        die('Access denied');
    }
}
```

### 3.3 共有機能を実装しない

意図的に以下の機能を実装しない（または制限する）。

**禁止すべき機能:**
- ユーザー間での書籍データ共有
- 公開URL生成
- 書籍データの外部公開API
- SNSへの書籍データ直接投稿（感想のテキスト投稿は可）

### 3.4 利用規約・免責事項の明示

ユーザーに対して、利用条件を明確に伝える。

**表示すべき内容:**
- 本サービスは私的使用の範囲内での利用を前提としている
- アップロードするファイルは、ユーザー自身が合法的に所有する書籍のスキャンデータに限る
- 第三者の著作物を無断でアップロード・共有することは禁止
- 著作権法に違反する利用について、運営者は責任を負わない

**表示タイミング:**
- 初回利用時（同意画面）
- アップロード画面
- フッター（利用規約リンク）

### 3.5 アップロード時の確認ステップ

ユーザーがアップロードする際に、著作権に関する確認を挟む。

```
┌─────────────────────────────────────────┐
│  ファイルアップロード                      │
│                                          │
│  ☑ このファイルは自分が所有する書籍を      │
│    スキャンしたものです                    │
│  ☑ 第三者と共有する目的ではありません      │
│                                          │
│  [変換開始]                               │
└─────────────────────────────────────────┘
```

**法的効果:**
- 免責の根拠になる（ユーザーが虚偽申告した場合の責任転嫁）
- 悪意のある利用を抑止する心理的効果

### 3.6 ログの記録と保持

不正利用の調査に備えて、最低限のログを記録する。

**記録すべき情報:**
- アップロード日時
- ファイルサイズ・ページ数（ファイル内容は保存しない）
- ユーザー識別子（IPアドレスまたはアカウントID）
- ダウンロード日時

**記録すべきでない情報:**
- ファイルの内容・画像データ
- 書籍のタイトル（プライバシー配慮）

### 3.7 DMCA / 著作権侵害通報への対応体制

万が一、著作権者から通報があった場合の対応フローを用意する。

**対応フロー:**
1. 通報受付窓口を設置する（メールアドレス等）
2. 該当データの即時削除
3. 該当ユーザーへの通知
4. 繰り返し違反者のアカウント停止

## 4. アーキテクチャ上の推奨設計

### 4.1 クライアント完結型を基本とする

最もリスクが低いのは、サーバーを経由しない設計。

```
推奨アーキテクチャ:

[ユーザーのブラウザ]
  ├── PDF/ZIP読み込み（クライアントサイド）
  ├── WebP変換（クライアントサイド）
  ├── .yomii生成（クライアントサイド）
  ├── IndexedDB保存（クライアントサイド）
  └── 閲覧（クライアントサイド）

[サーバー]
  └── アプリ本体の配信のみ（書籍データは一切通過しない）
```

**現状の課題:**
- PDF→画像変換はクライアントサイド（PDF.js）で対応済み
- ZIP展開もクライアントサイド（Zlib.js）で対応済み
- WebP変換のみサーバーに依存している

**改善案:**
- Canvas API の `toBlob('image/webp')` でクライアントサイドWebP変換を実装する
- これにより、サーバーに書籍データを送信する必要がなくなる

```javascript
// クライアントサイドでのWebP変換
async function convertToWebP(canvas, quality = 0.5) {
    return new Promise(resolve => {
        canvas.toBlob(resolve, 'image/webp', quality)
    })
}
```

### 4.2 ユーザー自身のクラウドストレージを活用する

著作権リスクの観点でも、ユーザー自身のクラウドストレージ（Google Drive / pCloud 等）に書籍データを保存する設計は有効。

**法的メリット:**
- Yomii のサーバーに書籍データが一切存在しない
- ユーザーが自分のストレージに自分のデータを置いているだけ（私的複製の範囲内）
- 「送信可能化」に該当しない（不特定多数がアクセスできる状態ではない）
- サービス運営者が著作物の複製・保管に関与していない構造になる

```
[ユーザーのブラウザ] ←→ [ユーザーのGoogle Drive / pCloud]
                              ↑
                    ユーザー自身のアカウント・ストレージ
                    Yomiiサーバーは一切関与しない
```

**設計ポイント:**
- Yomii はストレージへのアクセスを「仲介」するだけで、データを中継・保存しない
- OAuth トークンもクライアントサイドで管理し、サーバーを経由しない
- これにより「自炊代行」問題を完全に回避できる

### 4.3 サーバー変換が必要な場合の設計

高品質な変換（pdftoppm等）が必要な場合は、以下の原則を守る。

```
原則:
1. データは暗号化して送信する
2. サーバーでの保持時間を最小化する
3. 変換完了後は即座に削除する
4. サーバー管理者もデータにアクセスできない設計にする（E2E暗号化）
```

### 4.3 有料ストレージ機能の場合

サーバーに書籍を保存する有料機能を提供する場合:

- ユーザーごとに暗号化して保存する（サーバー管理者も閲覧不可）
- 共有機能は一切提供しない
- 利用規約で私的使用に限定する旨を明記する
- 著作権者からの削除要請に即座に対応できる体制を整える

## 5. 利用規約に含めるべき条項

```markdown
## 利用規約（要点）

1. 本サービスは、ユーザーが合法的に所有する書籍の私的使用を
   支援するツールです。

2. ユーザーは、自身が著作権を有する、または私的使用の範囲で
   複製する権利を有するファイルのみをアップロードできます。

3. 第三者の著作物を無断で複製・配布する目的での利用は禁止します。

4. アップロードされたデータは変換処理完了後、速やかにサーバーから
   削除されます。サーバーに書籍データを永続的に保存しません。

5. 本サービスの利用により生じた著作権法上の問題について、
   運営者は責任を負いません。利用者自身の責任において
   適法な範囲でご利用ください。

6. 著作権者からの正当な申し立てがあった場合、該当データの
   削除およびアカウントの停止を行う場合があります。
```
